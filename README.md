# ExamPrep for Windows

Download **ExamPrep 1.0.0** for Windows 10 and Windows 11 (64-bit).

ExamPrep is entrance and exit exam practice from **YomTech**. Author: **Amanuel M.**

## Download

[Download ExamPrep for Windows (Setup)](https://github.com/Zeaman/ExamPrep-Windows/releases/download/v1.0.0/ExamPrep-1.0.0-Windows-Setup.exe)

The Setup installer adds a Start menu entry and a desktop shortcut. The default folder is `C:\Program Files\ExamPrep` or `%LOCALAPPDATA%\Programs\ExamPrep`.

Direct file: [ExamPrep-1.0.0-Windows-Setup.exe](https://github.com/Zeaman/ExamPrep-Windows/releases/download/v1.0.0/ExamPrep-1.0.0-Windows-Setup.exe)

## Install

1. Open the Setup file.
2. If Windows shows “Windows protected your PC”, choose **More info**, then **Run anyway**. The installer is published by YomTech and is not yet code-signed.
3. Keep **Desktop shortcut** and **Start menu** checked.
4. Open **ExamPrep** and start a practice paper or a test.
